Guide d’utilisation

Retrouvez ici les principales étapes pour utiliser Smart Attendance. Choisissez la section correspondant à votre rôle ; les menus et actions disponibles dépendent des droits associés à votre compte.

Étudiant Professeur Chef de département Administrateur

Avant de commencer

Connexion

Ouvrez la page de connexion, saisissez l’adresse e-mail et le mot de passe liés à votre compte, puis sélectionnez « Se connecter ». Le système ouvre automatiquement l’espace correspondant au rôle du compte. Les comptes professeur et chef de département peuvent nécessiter une validation préalable de l’administration.

Navigation et thème

Sur les dashboards, utilisez le menu latéral (bouton burger sur petit écran) pour passer d’une section à l’autre. Le bouton « Thème » alterne entre les modes clair et sombre ; le choix est conservé. Le guide est aussi accessible depuis le pied de page.

Compte et sécurité

La rubrique « Profil et sécurité » ou « Informations et sécurité » récapitule les informations du compte. Pour modifier l’adresse e-mail ou le mot de passe, suivez les contrôles affichés et confirmez avec votre mot de passe actuel si cela est demandé. Les informations désactivées sont en lecture seule.

En cas de problème

Vérifiez votre connexion, les filtres actifs et les informations fournies. Si un cours, une classe ou une action attendue n’apparaît pas, contactez le chef de département ou l’administrateur selon le cas. Déconnectez-vous sur un appareil partagé.

Guide par rôle

Espace étudiant

  1. 1. Créer un compte et se connecter

    Depuis la page d’inscription, choisissez le profil étudiant et renseignez les informations demandées, notamment le département, la classe et le code de carte. Utilisez ensuite votre e-mail et votre mot de passe pour accéder au dashboard étudiant.

  2. 2. Retrouver ses cours

    La section « Mes cours et présences » affiche les cours auxquels vous êtes inscrit. Les filtres du menu latéral permettent de distinguer tous les cours, les cours actifs et les cours achevés. Utilisez la recherche, le nombre d’éléments par page et la pagination pour retrouver un cours.

  3. 3. Rejoindre un cours

    Sélectionnez « Rejoindre un nouveau cours » dans la page ou le menu. Choisissez un cours disponible correspondant à votre classe et votre département, sélectionnez « Rejoindre », saisissez le code d’enregistrement communiqué par le responsable du cours, puis validez. Le cours rejoint sera ensuite visible dans votre liste.

  4. 4. Consulter ses présences

    Dans la carte du cours concerné, cliquez sur « Voir mes présences ». La fenêtre affiche le registre du cours, les dates de séance et votre taux de présence calculé à partir des journées où l’appel a été effectué.

  5. 5. Vérifier les informations du profil

    Dans « Profil et sécurité », la classe et le code de carte sont affichés comme informations non modifiables, avec le nom, le matricule et le département. Pour modifier les informations de connexion, utilisez « Modifier le profil » et suivez les étapes affichées.

Guide par rôle

Espace professeur

  1. 1. Consulter les cours assignés

    La page « Mes cours assignés » liste les cours attribués par le chef de département. Utilisez les filtres Tous les cours, Cours actifs, Cours achevés ou Cours futurs, ainsi que la recherche et la pagination. Les cartes sont informatives : utilisez les boutons d’action qu’elles contiennent.

  2. 2. Ouvrir le registre

    Sélectionnez « Registre » sur la carte du cours. Le registre rassemble les étudiants inscrits, leurs présences par date et la colonne « Code carte ». Les journées sans appel sont indiquées comme non prises. Utilisez les boutons dédiés pour exporter le registre en Excel ou en PDF.

  3. 3. Faire l’appel

    Sélectionnez « Faire l’appel ». Le démarrage nécessite des étudiants inscrits. Scannez la carte de l’étudiant ou saisissez son code dans le champ prévu, puis vérifiez le retour affiché. Le code carte est celui associé au compte étudiant. Sélectionnez « Finir l’appel » quand la séance est terminée.

  4. 4. Gérer son compte

    La rubrique « Profil et sécurité » permet de consulter les informations du compte et de mettre à jour les éléments modifiables, comme l’e-mail, le mot de passe ou la photo de profil lorsque l’option est disponible.

Guide par rôle

Espace chef de département

  1. 1. Suivre les cours et les élèves

    Le menu donne accès à la gestion des cours et à la liste des classes et étudiants du département. Les compteurs et filtres permettent de distinguer cours actifs, achevés et futurs. Dans la liste des élèves, filtrez par classe ou année académique et consultez une classe avec son bouton d’action.

  2. 2. Créer un cours

    Dans « Gestion de mes cours », sélectionnez « Créer un nouveau cours ». Renseignez le nom, l’année académique, le code du cours, la classe, le professeur à assigner, le code d’enregistrement et les dates. Vérifiez les informations avant la création ; le professeur assigné pourra ensuite consulter le cours dans son dashboard.

  3. 3. Consulter et gérer les cours

    Sur chaque carte, « Voir le cours » ouvre le registre et les détails des élèves inscrits ; les exports Excel et PDF sont disponibles depuis cette vue. « Gérer le cours » permet de modifier les éléments proposés par le formulaire de gestion. « Supprimer » est une action à confirmer : vérifiez attentivement les avertissements avant de continuer.

  4. 4. Consulter les classes

    Dans l’espace des élèves, utilisez les filtres et la recherche pour trouver une classe. « Voir les élèves » affiche les étudiants associés à cette classe ainsi que les informations de promotion disponibles.

  5. 5. Gérer le profil

    La rubrique « Profil et sécurité » contient les données du compte. Utilisez les commandes de modification pour l’e-mail, le mot de passe ou la photo lorsque ces options sont proposées.

Guide par rôle

Espace administrateur

  1. 1. Lire le tableau de bord

    Les cartes statistiques et les onglets donnent accès aux départements, aux inscriptions en attente, aux chefs de département, aux professeurs et à « Info et sécurité ». Les cartes de contenu s’ouvrent à l’aide de leurs boutons dédiés.

  2. 2. Créer et consulter les départements

    Dans l’onglet « Départements », recherchez un département ou créez-en un avec le formulaire. Le bouton « Consulter » ouvre le détail et les classes associées. Vous pouvez ajouter une classe si la limite affichée le permet, consulter ses élèves et cours, ou supprimer un élément.

  3. 3. Traiter les inscriptions en attente

    Ouvrez l’onglet correspondant aux chefs ou aux professeurs en attente, vérifiez les informations de la demande, puis choisissez « Confirmer » ou « Supprimer ». Toute suppression ou tout remplacement de chef est potentiellement définitif : lisez et confirmez attentivement le dialogue de sécurité.

  4. 4. Consulter les comptes

    Les onglets « Chefs de départements » et « Professeurs » proposent la recherche et des fiches de compte. Utilisez « Détails et actions » pour ouvrir les options disponibles pour le compte concerné.

  5. 5. Gérer les codes administratifs

    Dans « Info et sécurité », consultez les codes disponibles pour les prochaines inscriptions de professeurs et de chefs de département. « Actualiser » recharge les codes ; « Anciens codes » ouvre l’historique. Communiquez les codes uniquement aux personnes autorisées et traitez l’historique selon les règles de votre établissement.

  6. 6. Confirmer les actions sensibles

    La suppression d’un département ou d’une classe peut entraîner la suppression de données liées, comme des cours, inscriptions ou présences. Consultez le message de confirmation avant toute opération irréversible et n’agissez que si vous êtes certain de la demande.
